CISM Master Exam - offline phone app

EASIEST (no hosting): open cism-master-exam.html on your phone.
  Android: save it to Downloads, open with Chrome.
  iPhone: the Files app preview won't run the quiz. Host it (below) or open it in an app that runs web pages.

AS A HOME-SCREEN APP (works offline after first open):
  1. Upload this whole folder to any static host (Netlify Drop, GitHub Pages, Cloudflare Pages).
  2. Open the site URL on your phone.
  3. iPhone Safari: Share > Add to Home Screen.  Android Chrome: menu > Install app.
  Your practice progress is saved on the phone only.
  Note: a public URL means anyone with the link can see your scores.
